This repository contains an end-to-end data pipeline built for the Website Sessions Data Pipeline quiz. The goal was to replicate a real-world data workflow by extracting session data for December 2023 from a MySQL source, loading it into a Postgres raw table, transforming it through modular dbt models (staging and warehouse layers), and finally visualizing the insights in Looker Studio. The pipeline uses Python, Pandas, and SQLAlchemy for ELT, automated through GitHub Actions with secrets for secure credentials. dbt handles clean transformations, creating models like stg_website_sessions and fct_website_sessions_utm_source_daily. In Looker Studio, the final dashboard brings the data to life with tables, a heatmap, a scorecard, and interactive charts that support cross-filtering for stakeholder-friendly exploration. This project combines tying together engineering, analysis, and storytelling through data.
